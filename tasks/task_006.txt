# Status: pending

# Description: Improve data not found handling and optimize loading speeds for better user experience

## 🔍 **Analysis Results**

### **Current Performance Issues:**
- **Known Stablecoins (USDT, USDC)**: 5-10 seconds loading time
- **Unknown Stablecoins (FRAX, new tokens)**: 10-18 seconds loading time
- **Major Bottleneck**: Transparency discovery timeout (5-8 seconds)
- **Critical Issue**: 0 scores mislead users (implies "terrible" not "unknown")

### **Key Findings:**
1. **Data Not Found = 0 Score Problem**
   - Line 444: `complete_risk_scores: { overall: 0, peg_stability: 0, transparency: 0, liquidity: 0, audit: 0 }`
   - Line 877: `return { score: 0, details: { error: 'Failed to fetch liquidity data' } };`
   - Users can't distinguish "bad data" vs "no data"

2. **Performance Bottlenecks:**
   - Sequential API calls instead of parallel execution
   - No caching layer (every request hits external APIs)
   - Heavy transparency discovery with 5-8s timeout
   - Missing progressive loading (users wait for all data)
